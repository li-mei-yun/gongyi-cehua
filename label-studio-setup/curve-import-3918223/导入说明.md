# 已标注拧紧曲线导入示例

本包只转换 `3918223.xlsx`，不代表已迁移全部曲线；没有修改原始 Excel，也未在 Label Studio 中创建项目或导入任务。

## 已核对的数据

- 曲线：Sheet1!A1:D616，表头 + 615 个采样点。
- 列：ID、结果 ID、扭矩 (N·m)、角度 (度)。
- 对应标签：label.xlsx 的 Sheet1!A2:C2，`3918223.xlsx / 0 / initial`。
- `labels` 与 `curve_type` 是两个独立分类字段，不把复拧解释为异常。
- 标签总表含 12,981 个唯一文件名：正常＋正常拧紧 9,848；异常＋正常拧紧 92；正常＋复拧 3,041；异常＋复拧 0。这只是原标签分布，不是重新判定质量。

## 导入步骤

1. 打开本机 Label Studio（http://localhost:8080），登录后新建一个试验项目，例如“拧紧曲线迁移测试”。
2. 在项目的 **Settings → Labeling Interface → Code** 中，粘贴 `project_config.xml` 的全部内容并保存。
3. 在项目中点击 **Import**，选择 `tasks_3918223.json`，完成导入。无需另外上传 Excel 或 CSV。
4. 打开这条任务，检查两个曲线通道和已有选项：**正常曲线**、**正常拧紧**。已有结果在 `annotations` 中，而非待确认的 `predictions`。
5. 确认显示正确后，再考虑批量转换其余原始曲线。避免反复导入同一个 JSON，以免产生重复任务。

## 横轴与数据保真

- 横轴使用原始 ID 1～615，是采样点编号，不是秒；未假设采样周期。
- 扭矩和角度作为两个通道展示，未生成“扭矩随角度”的单一 XY 图。
- 原始角度存在 187 次相邻回退，不能直接作为要求排序的时间横轴，也不能擅自按角度排序。
- 没有删除负值、平滑、截取、重采样或对数据取整；界面显示三位小数不改变存储精度。
- 全部 615 点内嵌在 JSON 中。样例不依赖 `D:` 盘容器挂载或外部文件服务，也不需要修改 Docker/Dify 配置。
- 现有标注只有整条曲线分类，没有异常区间。转换不会凭空添加异常起止位置。

## 标签对应关系及导出注意

| 导入后的分类字段 | 显示选项 | 原始编码 |
|---|---|---|
| quality | 正常曲线 | labels = 0 |
| quality | 异常曲线 | labels = 1 |
| tightening_type | 正常拧紧 | curve_type = initial |
| tightening_type | 复拧 | curve_type = retighten |

`data.source_labels_code` 与 `data.source_curve_type` 是导入前的历史编码，后续编辑标注时不会自动变化。训练或重新导出标签时，应读取最新 `annotations.result`，按上表映射，不能把历史编码当作修改后的标签。若同一任务有多条人工标注，需要事先定义选取或审核规则。
