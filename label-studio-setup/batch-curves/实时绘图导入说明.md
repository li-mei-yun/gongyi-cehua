# Label Studio Community Edition 实时绘制扭矩—角度曲线

Label Studio 原生 TimeSeries 要求横轴排序，不能可靠表示本数据中会回退、重复的角度。ReactCode 自定义绘图只在 Enterprise 提供。因此，本方案让 Label Studio 的 HyperText iframe 加载本机只读绘图页，由浏览器用 Canvas 实时绘制，不存储曲线图片。

## 已验证

- 12,981 条曲线、7,831,497 个采样点和原有 annotations 保持不变。
- 新包 `package-scu2020-live`：67批、322,880,302字节、预生成图片0张。
- 实时页按采样顺序连接角度和扭矩；滚轮缩放、拖动平移、双击复位及悬停读数通过浏览器测试。
- Label Studio 1.23.0 模板校验和完整包干运行通过。
- 绘图服务只监听 `127.0.0.1:8091`，不对局域网开放；只读原转换缓存，不写原始Excel或Label Studio数据库。

## 使用要求

- 打开曲线任务时，`start_plot_server.ps1` 必须已启动；电脑重启后要重新运行。服务未启动时标签数据仍在，但图形区域无法加载。
- Label Studio 和浏览器都在这台电脑使用时无需额外网络配置。若以后让局域网其它电脑标注，任务中的 `127.0.0.1` 会指向对方电脑，需改为受控的服务器地址并配置访问控制。
- 不要导入 `package-scu2020-xy`，它是较早的预生成图片方案；新需求应使用 `package-scu2020-live`。
- 不要删除或移动 `package-scu2020/conversion_cache.sqlite3`，实时服务从中只读曲线数值。
